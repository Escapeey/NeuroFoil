# v0.0.1 · 项目初始化

> 版本号：`v0.0.1`（大版本.中版本.bugfix）
> 日期：2026-11-25
> 对应开发者日志：[`docs/archive/CHANGELOG.md`](../CHANGELOG.md)

## 改动原因

- 需要对「手机端宝可梦光栅卡 · 神经渲染」启动技术穿刺，需要一个可回溯、可协作的工程起点。
- 原始需求只有 3 行草稿，需先补全为可执行的需求说明书。

## 改动方案

- **方案 A**：直接在草稿上迭代需求，不建立归档体系。
- **方案 B**：建立「版本号 + 变更文档 + 开发者日志 + git」的归档体系，先定稿需求再启动编码。

## 最终改动方案

- 采用方案 B。
- 选定工程名 **NeuroFoil**。
- 建立归档体系：`docs/archive/CHANGELOG.md` + `docs/archive/version/v0-0-1.md` + 版本模板 `_TEMPLATE.md`。
- 补全需求说明书：冻结神经纹理 8 入参架构，明确目标 / 验收指标、穿刺范围与待定项。

## 改动结果

- 需求说明书定稿：`需求说明书.md`
- 归档体系就位，开发原则写入 `README.md`
- 明确 PC 穿刺范围：512×512@60fps、视角 ±45°、交付 `size ↔ quality ↔ latency` 曲线

## 遗留事项

- 模型体积预算未定（待穿刺产出 size ↔ quality 曲线后定工作点）。
- 视差表达未定（暂定网络从含视差 GT 隐式学习）。
- 角度来源（陀螺仪 vs 眼球追踪）未定（属端侧落地，超出本次）。
- 俯仰 / 旋转角的轴定义尚未与 GT 渲染管线对齐。

## 风险点

- 逐像素 MLP 在 512×512@60fps 下的算力是否可控（首要风险）。
- 小网络能否学到文字 / 线稿等高频细节（需靠显式 uv 输入缓解）。
